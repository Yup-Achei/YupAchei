# Registros de Decisões Arquiteturais (ADRs)

Este diretório contém os Architecture Decision Records (ADRs) do projeto **YupAchei**.

---

## Estrutura de um ADR

Toda decisão arquitetural significativa que altere padrões, tecnologias ou limites arquiteturais deve ser registrada utilizando o formato:

- **Título:** Número sequencial e nome descritivo (ex.: `0001-adocao-clean-architecture.md`).
- **Status:** Proposto | Aprovado | Rejeitado | Substituído.
- **Contexto:** Qual é o problema ou necessidade técnica que motivou a decisão?
- **Decisão:** O que foi decidido e qual abordagem será implementada?
- **Consequências:** Quais são os benefícios obtidos e as limitações/custos assumidos?
