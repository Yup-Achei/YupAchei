# Triage Labels

As skills operam com base em cinco papéis canônicos de triagem. A tabela abaixo mapeia os papéis aos rótulos adotados no repositório **YupAchei**.

| Label em mattpocock/skills | Label no repositório | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | Mantenedor precisa avaliar e priorizar a issue |
| `needs-info` | `needs-info` | Aguardando informações adicionais do solicitante |
| `ready-for-agent` | `ready-for-agent` | Especificação completa, pronta para execução por agente |
| `ready-for-human` | `ready-for-human` | Demanda que requer implementação exclusivamente humana |
| `wontfix` | `wontfix` | Demanda descartada ou fora do escopo |

> **Nota:** Não crie nem aplique labels diretamente no GitHub remoto sem autorização prévia.
