# YupAchei.WebApi

**API Web**

Controllers/Minimal APIs, Middlewares, configuração de Injeção de Dependência e documentação Swagger/OpenAPI. Ponto de entrada do backend.

## Estrutura sugerida

- `Endpoints/ ou Controllers/`
- `Middlewares/`
- `Extensions/ (DI)`
- `Program.cs`
- `appsettings.json`

## Dependências

YupAchei.Application, YupAchei.Infrastructure, YupAchei.Services
