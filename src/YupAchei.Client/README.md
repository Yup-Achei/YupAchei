# YupAchei.Client

**Frontend PWA**

Aplicação React + TypeScript construída com Vite, configurada como PWA (Progressive Web App) para uso mobile-first.

## Estrutura sugerida

- `src/components/`
- `src/pages/`
- `src/services/ (chamadas à API)`
- `src/hooks/`
- `public/ (manifest, ícones)`

## Dependências

Consome a YupAchei.WebApi via HTTP

> Veja o [README principal](../../README.md) para a visão geral da arquitetura.
